# 非遗小火苗 · 浏览器桌宠

沿用本仓库的 HTML / CSS / JavaScript 和 GitHub Pages。当前主要入口是浏览器桌宠原型，不需要安装 Electron 或使用外部动画平台。

唯一角色是仓库首次提交中的完整 `pet.png`，原文件未修改：火焰头发、五官、传统服饰及乐器都保留。页面没有额外的眼睛、腮红或手掌素材。所有角色动画均施加到 `.pet-art`，小型 Zzz 也绑定在这一容器中。

## 打开与开发

线上地址：https://rds54mbtv5-dotcom.github.io/amazing-pet/

本地需要 Node.js 24 LTS：

```sh
npm ci
npm start
```

然后打开终端输出的本地地址。也可直接打开 `index.html`，但建议用本地服务器获得稳定的位置存储行为。双击启动脚本和 `main.js` / `preload.js` 是之前保留的桌面入口；本次不新增桌面框架。旧桌面入口使用 `npm run start:desktop`。

## 交互

| 动作 | 触发与效果 |
| --- | --- |
| idle | 默认，2.8 秒一周期的轻微呼吸与浮动 |
| happy | 单击后等待 350 毫秒区分双击，整体跳跃并轻微回弹，0.7 秒后回到待机 |
| shy | 悬停 1.5 秒后整体小幅歪头摇摆，0.8 秒，不添加独立五官 |
| drag | 按住移动超过 5 像素后，整体跟随鼠标或触屏指针，轻微倾斜 |
| land | 松手后在原位置柔和回弹，0.42 秒，无明显挤压变形 |
| sleep | 4 分钟无互动，降低呼吸幅度并在角色头顶附近显示小型 Zzz；点击唤醒 |
| greet | 首次打开或学习庆祝时整体轻跳摇摆，1 秒，无额外手掌 |
| playInstrument | 同一位置 350 毫秒内双击，整体随节奏摇摆 3 秒，乐器保持原位 |

拖拽后不会触发跳跃。双击不会先触发一次单击动作。Enter / 空格支持单击反馈。

拖动停止时将页面坐标保存到当前浏览器的 `localStorage`，刷新后恢复；缩小窗口后会把角色限制在可见范围。存储被禁用或损坏时回退到可用状态，不影响拖动。不会上传鼠标或位置数据。

页面使用简洁暖色背景，首次居中显示角色；顶部名称和底部小字只提供交互提示。浏览器不能提供操作系统桌面悬浮、置顶或透明无边框窗口。

## 状态、资源和功能扩展

- `index.html`：唯一角色根节点、原图、小型 Zzz 和气泡；没有 SVG 替代肢体。
- `style.css`：角色自身坐标系中的整体动画、响应式居中及减少动态效果支持。
- `pet-state.js`：状态与时长，优先级为 drag > land > playInstrument > happy > shy > greet > sleep > idle。强制落地发生在拖拽结束，动作切换会取消旧的结束计时。
- `renderer.js`：命名计时器、单双击判定、指针捕获、位置存储、睡眠和提醒；初始化防重，使用 AbortController 清理事件。页面隐藏时暂停自动行为，恢复或从浏览器返回缓存恢复时重新安排计时。失焦和指针取消会安全结束拖动。
- `scripts/build-web.cjs`：将网页发布至 `_site/`，为 CSS、JS 和原图生成内容指纹文件名，避免 HTML 与旧缓存 CSS 混用。
- `scripts/serve.cjs`：仅供本地开发和测试的静态服务器。
- `tests/state.test.cjs`、`tests/browser/pet.spec.cjs`：状态及浏览器交互回归检查。

保留气泡、低频非遗知识提醒和 `pet:celebrate` 学习庆祝事件。90 秒后首次尝试知识提醒，此后每 3 分钟尝试，睡眠或正在交互时不打扰。未来知识卡片、问答和每日推荐可以调用气泡和状态接口，无需重写动作系统。

任务完成时可触发：

```js
window.dispatchEvent(new Event('pet:celebrate'));
```

当前原图为单张完整 PNG，不含分层素材，因此本版不单独眨眼、移动手臂或拨动琴弦，也不添加演奏音频。若未来需要精细演奏、眨眼或局部火焰动作，需要同一角色、同一比例的原始分层素材或成套动作帧，不能以新角色替代。

## 验证与发布

```sh
npm run check
npm test
npm run build:web
npx playwright install chromium
npm run test:browser
```

浏览器测试针对真实构建产物，覆盖原图一致性、单一角色、桌面及手机布局、单击和双击互斥、悬停、拖拽回弹、位置持久化与缩放边界、睡眠唤醒、知识提醒、键盘、指针取消、损坏存储及减少动态效果。测试使用可控时间，不需要真的等待 4 分钟。

推送 `main` 后，现有 **Publish web preview** 工作流依次检查语法、运行状态测试、构建网页并在 Chromium 中运行交互测试，通过后才发布 GitHub Pages。也可在 Actions 手动运行该工作流。失败时不会替换当前已发布的网页。修改脚本和样式时不用另建网站。

原有 **Build desktop pet** 工作流继续保留历史桌面构建，不是使用浏览器原型的前提。
